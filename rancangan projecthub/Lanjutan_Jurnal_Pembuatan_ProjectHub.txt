LANJUTAN JURNAL PEMBUATAN APLIKASI PROJECTHUB

Lanjutan dari langkah 13: Buka Terminal di VS Code

Petunjuk penulisan:
- Setiap nomor yang menyebut satu file hanya menggunakan satu gambar untuk file tersebut.
- Ganti placeholder [TEMPELKAN SATU GAMBAR ...] dengan satu screenshot kode.
- Langkah migration pertama berisi daftar command dalam satu gambar terminal. Setelah itu,
  setiap file migration dibahas di nomor tersendiri dengan satu gambar.
- Untuk model, controller, middleware, route, component, dan view, buat file melalui
  Explorer VS Code pada folder yang tertulis. Jangan gunakan command Artisan untuk membuat
  model atau controller pada bagian ini.
- File migration users sudah dibuat oleh Laravel. Edit file yang ada; jangan membuat
  migration users baru. Migration cache dan jobs juga berasal dari Laravel.
- Catatan sesuai source akhir: ProjectHub menggunakan Laravel 13 dan autentikasi khusus.
  Breeze tidak tercantum sebagai dependency pada source akhir. Langkah Breeze di bawah
  hanya berlaku jika memang dipasang saat proses awal pembuatan aplikasi.


14. Membuat File Migration Aplikasi

Buka Terminal VS Code pada folder utama project. Jalankan command berikut satu per satu,
sesuai urutan:

php artisan make:migration create_projects_table
php artisan make:migration create_project_stages_table
php artisan make:migration create_project_members_table
php artisan make:migration create_tasks_table
php artisan make:migration create_task_assignees_table
php artisan make:migration create_subtasks_table
php artisan make:migration create_subtask_attachments_table
php artisan make:migration create_revision_items_table
php artisan make:migration create_project_completion_exceptions_table
php artisan make:migration create_revision_attachments_table

Laravel akan membuat nama file lengkap dengan timestamp secara otomatis di
database/migrations. Jalankan command sesuai urutan agar hubungan foreign key dibuat setelah
tabel yang dirujuk.

[TEMPELKAN SATU GAMBAR daftar command pembuatan migration di Terminal]


15. Buka file database/migrations/0001_01_01_000000_create_users_table.php dan isi dengan script di bawah.

Sesuaikan tabel users agar memiliki name, username, email, password, role,
status, profile_photo, department, skills, phone, joined_at, must_change_password,
rememberToken, dan timestamps. Pastikan tabel password_reset_tokens dan sessions tetap
sesuai kebutuhan aplikasi.

[TEMPELKAN SATU GAMBAR isi file 0001_01_01_000000_create_users_table.php]


16. Buka file database/migrations/[timestamp]_create_projects_table.php dan isi dengan script di bawah.

Tabel projects memiliki kolom created_by, name, description, start_date, deadline, status,
dan timestamps.
Kolom created_by merupakan foreign key ke users. Status awal proyek adalah draft.

[TEMPELKAN SATU GAMBAR isi file create_projects_table.php]


17. Buka file database/migrations/[timestamp]_create_project_stages_table.php dan isi dengan script di bawah.

Tabel project_stages memiliki kolom project_id, name, position, completed_at, dan
timestamps. Tambahkan
current_stage_id nullable sebagai foreign key pada tabel projects. Pada method down(),
hapus foreign key current_stage_id sebelum menghapus tabel project_stages.

[TEMPELKAN SATU GAMBAR isi file create_project_stages_table.php]

26. Menjalankan Migration

Setelah semua migration selesai diisi, jalankan perintah berikut:

php artisan migrate

Pastikan seluruh migration berhasil dijalankan. Jika terjadi error foreign key, periksa
urutan timestamp dan nama tabel yang dirujuk.

[TEMPELKAN SATU GAMBAR hasil perintah php artisan migrate]


27. Menginstal Laravel Breeze (Hanya Jika Digunakan pada Proses Awal)

Jika proses awal pembuatan aplikasi memang menggunakan Breeze, jalankan command berikut:

composer require laravel/breeze --dev
php artisan breeze:install
npm install

Pilih Blade jika installer meminta pilihan stack. Breeze menyediakan scaffold autentikasi
awal yang dapat disesuaikan.

Catatan: source akhir ProjectHub tidak menggunakan Breeze. Autentikasi akhirnya memakai
AuthController, routes/auth.php, dan halaman login khusus. Jika jurnal menjelaskan source
akhir, jelaskan bahwa autentikasi disesuaikan sendiri; jangan menyebut Breeze sebagai
dependency yang masih dipakai.

[TEMPELKAN SATU GAMBAR proses instalasi Breeze jika memang dilakukan]

[TEMPELKAN SATU GAMBAR hasil perintah php artisan route:list]


59. Build Asset Frontend

Sebelum menjalankan aplikasi, buat asset frontend untuk digunakan oleh website:

npm run build

Pastikan proses build selesai tanpa error agar CSS dan JavaScript tersedia di public/build.
Jika dependency frontend belum terpasang, jalankan npm install terlebih dahulu.

[TEMPELKAN SATU GAMBAR hasil perintah npm run build]


60. Menjalankan Aplikasi

Jalankan server Laravel dari Terminal:

php artisan serve

Buka alamat lokal yang ditampilkan Terminal pada browser. Asset yang telah di-build akan
digunakan oleh website. Coba login dan pastikan halaman tampil sesuai role admin,
project_manager, atau employee.

[TEMPELKAN SATU GAMBAR aplikasi yang berjalan setelah php artisan serve]
